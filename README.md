# Learning Platform with Smart Study Planner

## Project Overview
The Learning Platform with Smart Study Planner is a web-based application designed to help students manage their learning activities efficiently. The platform provides features like quiz management, assessment handling, notes management, and smart study planning.

## Features
- User Registration and Login
- User Dashboard
- Admin Dashboard
- Quiz Management Module
- Assessment Module
- Notes Management
- Study Planner
- Progress Tracking

## Technologies Used
- Java
- JSP & Servlet
- HTML
- CSS
- JavaScript
- MySQL

## Modules
### User Module
- Login/Register
- Access Notes
- Attempt Quizzes
- View Assessments

### Admin Module
- Manage Users
- Upload Notes
- Create Quizzes
- Manage Assessments

## Project Objective
To improve student productivity and learning management through a centralized online platform.
